# Учебный проект: Автотесты REST API на Python (pytest + requests)

Здесь собраны мои первые автотесты для проверки учебного REST API сервиса [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## Что используется в проекте:
- **Python + библиотека `requests`** — для отправки HTTP-запросов (`GET`, `POST`, `DELETE`) к серверу.
- **Фреймворк `pytest`** — для запуска тестов в терминале и проверки ответов сервера через `assert`.
- **GitHub Actions (`ci.yml`)** — базовый конвейер CI, который автоматически запускает команду `pytest -v` при отправке изменений в репозиторий.

## Какие тест-кейсы проверяются (файл `test_api.py`):
1. **TC-01 (`GET /users/1`):** Позитивный тест — получение существующего пользователя, проверка статус-кода `200 OK` и полей `id`, `username` в JSON.
2. **TC-02 (`GET /users/99999`):** Негативный тест — запрос несуществующего пользователя за границами списка, проверка кода `404 Not Found`.
3. **TC-03 (`POST /posts`):** Позитивный тест — создание нового поста с отправкой JSON-тела, проверка кода `201 Created` и сохранение полученного `id`.
4. **TC-04 (`DELETE /posts/{id}`):** Позитивный тест — удаление созданного в TC-03 поста по его `id`, проверка кода `200 OK`.

## Как запустить тесты на компьютере:
Установить библиотеки из списка `requirements.txt` и запустить `pytest`: (Откройте терминал в папке проекта)
```bash
pip install -r requirements.txt
pytest -v
```
